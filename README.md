# CortesByLRM

Operação de cortes verticais assistida por IA, com foco em conteúdo **autorizado**, qualidade e mensuração de receita, sem necessidade de aparecer.

> Estado: P0 em desenvolvimento. Ainda não há automação de publicação, promessas de viralização nem integração de pagamentos.

## Objetivo

1. Validar campanhas de cortes remunerados e serviços recorrentes de edição.
2. Usar uma esteira local: vídeo permitido → transcrição SRT → sugestões → revisão humana → corte 9:16.
3. Registrar URL publicada, visualizações elegíveis e **pagamentos recebidos** separadamente.
4. Testar o FilmCraft como alternativa, sem substituir o FFmpeg até passar por validação.

**Segurança:** este repositório é público. Não commitar vídeos de clientes, tokens, credenciais, PDFs de contrato ou material protegido.

A implementação inicial será desenvolvida em uma branch específica, com testes e instruções de uso antes de entrar na `main`.
